# 데이터 분석 첫번째 프로젝트

**링크**: [https://github.com/NR128/project_01_instagram_influencer_analysis.git](https://github.com/NR128/project_01_instagram_influencer_analysis.git)

## 개요
인스타그램 인플루언서에 대한 광고 효율 데이터 분석

## 개발환경
- **언어**: 파이썬 (Python)
- **라이브러리**: 판다스 (Pandas)
- **도구**: 구글 코랩 (Google Colab), 태블로 (Tableau)
- **데이터 출처**: 블로그

---

### 상세 설명
이 프로젝트는 인스타그램 인플루언서들의 광고 캠페인 성과를 데이터 기반으로 분석하기 위해 시작되었습니다. 주요 지표인 팔로워 대비 참여율(Engagement Rate), 광고 단가 대비 전환율(CVR) 등을 판다스를 활용해 전처리하고 분석했습니다. 

마지막으로 태블로 대시보드를 통해 직관적인 시각화 자료를 제작하여, 가장 광고 효율이 높은 인플루언서 카테고리를 도출해냈습니다.
